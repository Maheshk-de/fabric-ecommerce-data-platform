# Business Requirements

## Project
E-Commerce Unified Data Platform using Microsoft Fabric

## Business Problem
The e-commerce business receives customer, product, store, sales, inventory, returns and promotion data from multiple systems. Manual reporting creates inconsistent numbers, delays and limited visibility into sales and inventory.

## Objectives
- Build a centralized analytical platform using Microsoft Fabric and OneLake.
- Integrate SQL, file-based and API/JSON sources.
- Establish Landing, Bronze, Silver and Gold layers.
- Support incremental processing.
- Implement data-quality validation and error handling.
- Demonstrate SCD Type 2 for historical changes.
- Expose business-ready data through Fabric Warehouse, Semantic Model and Power BI.
- Implement reusable metadata-driven ingestion.

## Business Outcomes
- Single source of truth for sales, inventory, customer and product analytics.
- Faster and more reliable reporting.
- Better inventory visibility.
- Reduced manual reporting effort.
- Scalable data onboarding.

## Key Business Questions
1. What are revenue, profit and order trends?
2. Which products and stores perform best?
3. Which products are at risk of low stock?
4. What is the return rate and the main return reason?
5. How are repeat customers changing?
6. Which promotions contribute to sales performance?
